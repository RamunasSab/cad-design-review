# Security Policy

## Reporting a vulnerability

Please do not publish security-sensitive details in a public issue. Contact the repository maintainer privately through the contact method listed in the GitHub profile. Include the affected file, steps to reproduce, and potential impact.

## Safe use

Review bundled scripts and rule data before using them in production. Run scripts in an appropriately restricted environment and provide only the files needed for the review. This skill is an advisory engineering aid; it does not replace independent engineering verification or approval.
