# CAD Design Review v1.6.0 — Review templates and dimension-chain checks

Five process-specific review prompts and expanded dimension-chain guidance make it easier to start a structured review and evaluate functional limits. This release also adds a reproducible clearance example and clearer setup, evidence, and contribution documentation.

## Highlights

- Ready-to-copy prompts for machining, sheet-metal cutting/bending, injection molding, progressive stamping, and additive manufacturing.
- Expanded checks for closed dimension chains, redundant dimensions, functional open-chain limits, datums, symmetry, and centring.
- A worked shaft-to-hole clearance review with original/revised JSON inputs, verified worst-case results, and reproduction commands.
- A README quick start, version-channel guidance, agent-check records, contributor guide, and issue/PR templates.
- Node.js 24-based GitHub Actions and weekly Dependabot update proposals.

## Install v1.6.0

Requires Node.js 22.20+, npm, Git, and a compatible AI agent.

```bash
npx skills add RamunasSab/cad-design-review@v1.6.0 --global --all
npx skills ls --global
```

On Windows PowerShell, use `npx.cmd` if script execution policy prevents `npx.ps1` from running. Python 3 is required only for the bundled calculation utilities.

This tag-pinned command becomes available when the v1.6.0 tag is published. Existing v1.5.0 users can explicitly install v1.6.0 with the command above.

## Validation and compatibility

- Python compilation, repository smoke tests, and reference/example JSON validation completed during preparation.
- The clearance example produces 0.000–0.160 mm (FAIL) before revision and 0.040–0.160 mm (PASS) after revision.
- Hosted Linux utility/parser checks and a directed instruction-file review are documented separately from actual CLI installation.
- A user reported successful Skills CLI cloning, discovery, and copy installation on Windows; this does not verify Codex or Claude Code activation.
- A user-reported Claude AI case calculated the clearance correctly but included an incorrect recommendation, documented with a correction.

## Limitations

- Existing Python calculation logic, numeric rule datasets, and schemas are unchanged from v1.5.0.
- No automatic STEP, PDF, or DXF parser is added. File inspection depends on available host tools.
- Additive-manufacturing review remains manual guidance; no automated DfAM rules are added.
- Codex and Claude Code clean-session activation have not been certified.
- The skills.sh listing/content snapshot issue remains separate from repository installation; resolution is not claimed.
- Review findings remain advisory and require engineering verification.
